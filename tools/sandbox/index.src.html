What this tests, and what it can't
  • Real: the addon files themselves (Core.lua, GPS3D.lua and their data), unchanged, in a real Lua VM.
  • Real: the 3D terrain of every map that has outdoor terrain (heights from the game files, 16.7 yards apart), and the buildings of the whole world (54 MB of meshes, loaded at start as the game would; "buildings off/on" and 2000/4000/8000 set how many building triangles a frame may draw).
  • Real: the game's own minimap images for 131 tiles around Elwynn, Stormwind, Westfall, Redridge and Duskwood; elsewhere the sandbox shows the overview images the addon ships, so close-ups are blurrier than in the game.
  • Simulated: the WoW UI engine (frames, anchors, layers, mouse), your position and facing, zone names and map coordinates.
  • Not testable here: whether the game lets addons load minimap images by file ID, the real character model (a block figure stands in), the ModelScene's real camera conventions, and real frame times. Loaded counts in the self-tests describe the sandbox, not the game.
  • Lua here is 5.4; the game uses 5.1. The sandbox imitates 5.1 where the addon depends on it (number formatting).
